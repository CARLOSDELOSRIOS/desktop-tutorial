Cómo abrirlo

  1. En GitHub, usa Download raw file para guardar esta página HTML.
  2. Abre el HTML descargado con Chrome o Edge y pulsa el botón de descarga.
  3. Sobre el ZIP descargado, haz clic derecho y elige Extraer todo.
  4. Abre el PDF para leer o el Word para editar. En Word, tras hacer cambios, actualiza el índice con clic derecho → Actualizar campo → Actualizar toda la tabla.
Las pantallas son diseños propuestos. La ejecución en SQL Server y el despliegue en la nube siguen pendientes. Las 22 figuras se conservan dentro de Word y PDF; las fuentes permiten recuperarlas al regenerar el documento.
